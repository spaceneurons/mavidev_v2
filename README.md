# MAVI/dev

Адаптивная HTML/CSS/JavaScript-реализация лендинга. Для просмотра откройте `index.html` в браузере.

Десктопная версия сверялась с фреймом «новый хиро блок» (165:168, 1440 × 4925) из предоставленного экспорта Figma. Текстура, контуры логотипов, крупные заголовки и иконки получены из этого файла. Manrope и Inter загружаются локально. Для текста, оформленного в Figma шрифтом SF Pro, используется установленный системный шрифт с запасным Inter.

Мобильная версия адаптирует этот фрейм под узкие экраны. Экспорт содержит только десктопный фрейм.

В макете превью кейсов представлены серыми прямоугольниками. Кнопкам «Открыть» нужны адреса проектов. Форма позволяет скопировать текст заявки для самостоятельной отправки в Telegram. Серверный обработчик отсутствует.
