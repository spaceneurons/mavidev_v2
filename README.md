# MAVI/dev

Адаптивная HTML/CSS/JavaScript-реализация сайта по макетам Figma.

- Десктопный макет: https://www.figma.com/design/r6HZ3SVE7xa9mnxgrXibzQ/Untitled?node-id=1487-8889
- Мобильный макет: https://www.figma.com/design/r6HZ3SVE7xa9mnxgrXibzQ/Untitled?node-id=1660-6979

Откройте `index.html` в браузере.

**Статус:** первоначальная адаптивная версия. До визуального соответствия 1:1 необходима проверка композиции с оригинальными скриншотами и экспорт графических ресурсов/шрифтов из Figma. Формы и контактные адреса требуют подключения реальных реквизитов.
