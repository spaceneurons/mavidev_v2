# Публикация MAVI/dev на Hoster.by

Исходники для публикации лежат в `public/` и `src/`. Данные сайта хранится на хостинге в `data/` и `public/uploads/`. В репозиторий входят только исходники и статические ресурсы. Файлы заявок, пароли, токены, серверные конфиги и пользовательские загрузки остаются на хостинге.

Хостинг забирает текущий коммит `main` из публичного репозитория по HTTPS. Скрипт размещается в `~/.mavidev-deploy/hoster-pull.sh`, вне корня сайта. При обновлении скрипта его новую версию надо отдельно установить на хостинг.

1. Загрузить в `main` проверенные исходники в структуре `public/` и `src/`.
2. На хостинге выполнить `bash ~/.mavidev-deploy/hoster-pull.sh --check`. Команда проверяет состав и синтаксис PHP без изменения сайта.
3. Сделать первый запуск и проверить главную страницу и страницу входа в админку.
4. После проверки добавить одну задачу в планировщике Hoster.by с командой `/bin/bash "$HOME/.mavidev-deploy/hoster-pull.sh" >> "$HOME/.mavidev-deploy/publish.log" 2>&1`, например каждые пять минут.

Скрипт использует блокировку от параллельного запуска и переносит только файлы, присутствующие в проверенной версии. Файлы, которые не входят в релиз, остаются в исходных каталогах. Версии заменённых файлов сохраняются в `~/.mavidev-deploy/backup-*`.
